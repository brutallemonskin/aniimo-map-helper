地图、点位目录与角色识别模板。各地图 JSON 保留素材来源链接。

`player-number-1-template.png`、`player-number-2-template.png`、`player-number-3-template.png`
是 2026-10-11 本机实测画面中 1P／2P／3P 字形的二值裁切，仅包含编号字形，不含玩家昵称或其他画面。
1P 和 3P 取自地宫大地图，2P 取自游戏场景中的队员标签。素材权利仍归游戏权利人。
程序按本局选择的编号定位，颜色不用于决定谁是本地玩家。

`screen-team-template.png` 和 `screen-inventory-template.png` 仅包含同日手动采样的
“队伍”“背包”标题二值字形，用于跳过明确的非地图界面。字体或布局不匹配时不作跳过判断。
