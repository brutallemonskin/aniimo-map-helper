伊莫地图助手 v0.4.2 更新说明
相比 GitHub 当前 v0.4.1，同样只使用 WGC 本地采集。

1. 改善疑似彩虹光柱识别
结合亮芯、持续细长柱身、周边亮度对比，减少普通小光柱、紫色边缘等误判，改善宽光晕的漏检。
根据玩家提供的截图进行了缩放、压缩和亮度变体测试；样例结果不代表实际游戏准确率。标记仍是发现时玩家附近的近似位置，不是物品精确坐标，仍可能误报或漏报。

2. WGC 错误信息更具体
保留 Windows 原始 HRESULT，区分捕获接口创建和窗口捕获对象创建失败。
根据错误码提示服务通信、接口不可用、权限或窗口失效等方向；提示不是对系统故障根因的最终诊断。

3. 有限重试和窗口核对
仅对明确的捕获服务通信失败或断开重试一次，并检查目标窗口是否仍属于同一个进程。
权限拒绝、未知错误及原生进程崩溃不会盲目反复重试。保留原有独立采集进程和可选接口参数回退。

4. 旧系统提示
启动采集时记录 Windows build；低于 WGC 窗口接口最低要求的系统会直接提示（Windows 10 1903 / 18362）。达到最低版本不保证所有可选接口、驱动或游戏窗口都可采集。

5. 新增“采集兼容性诊断.exe”
双击后按 Enter，自动比较：原生捕获对象创建、官方原版库、当前库关闭跳帧、当前库开启 0.5 秒跳帧。
只采集自带的动态测试窗口，无需启动游戏、管理员权限或额外安装 Python。单组超时会终止，不影响助手服务。
结果保存在“诊断报告”文件夹内，请反馈本次“诊断结果.txt”和“report.json”。报告不会自动上传，不保存游戏截图。
四组样例测试通过不等于真实游戏或所有 Windows 版本均通过。

更新方式
先用“退出助手.exe”退出旧版，完整解压 aniimo_map_helper_v0.4.2.zip 到新文件夹，再运行“启动助手.exe”。不要覆盖正在运行的旧目录。
网页偏好沿用浏览器保存的设置；旧目录的悬浮窗位置和快捷键文件不会自动迁移。

已知限制
部分设备的 GraphicsCaptureItem 失败或 0xC0000409 启动崩溃尚未确认修复，本版不承诺解决所有兼容性问题。
未完成旧版 Windows 虚拟机实测。发布包不含 DXGI、Hyper-V 安装脚本、系统镜像、SDK、私人截图或开发测试集。
悬浮窗黑底减淡、普通海岛模式、默认 0.5 秒间隔已经包含在此前同版本更新的 v0.4.1，继续保留。
