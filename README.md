# 伊莫 · 地宫领航

《伊莫》抢蛋模式的本地地图助手。识别游戏地图，在地宫中跟踪玩家位置，并通过半透明置顶窗口展示地图。

## 下载与启动

在本仓库 **Releases** 页面下载 `AniimoNavigator-Portable-v0.3.8.zip`，完整解压后双击 **启动助手.exe**。

- Windows 10/11 x64，无需安装 Python，无需管理员权限。
- 请保留整个解压目录，不要在压缩包中直接运行。
- 建议使用 Chrome 或 Edge 打开助手；首次启动需要等待地图索引完成。
- 用完双击 **退出助手.exe**。仅关闭网页会停止该页面的共享与识别；后台服务和悬浮窗需要通过“退出助手”关闭，以释放内存和端口。

首次打开默认中文。可在右上角切换中文 / English，选择自动记忆，切换不重置地图与位置。英文游戏客户端画面兼容性尚待实测。

## 使用

1. 点击“选择游戏窗口”，选择完整的伊莫游戏窗口。
2. 进入地宫后打开一次游戏大地图，等待确认地图和角色位置。
3. 关闭大地图后，通过左上角小地图继续定位；进入下一局点击“新一局”。
4. 点击“游戏悬浮窗”，即可在游戏上方查看地图。

悬浮窗可拖动标题栏移动、拖动边缘或角落等比例缩放，自动记住位置、大小和透明度。标题栏 `− / +` 调整透明度。

| 快捷键 | 功能 |
| --- | --- |
| Alt+Shift+M | 切换鼠标穿透，解锁后可移动、缩放 |
| Alt+Shift+H | 隐藏或显示悬浮窗 |

## 已有功能

- 33 张本地地图，含地宫、奖励房及普通/小队海岛。
- 大地图匹配，识别后自动切换地图。
- 小地图定位，支持黄色角色箭头及蓝白星纹蛋形态。
- 背包等界面遮挡地图时保留最后位置，恢复后继续定位。
- 海岛分区显示、点位筛选、半透明游戏悬浮窗。
- 可选择 0.25 秒、0.5 秒、1 秒、2 秒、3 秒识别间隔，自动保存；默认 0.25 秒。
- 复用未变化的小地图定位结果；缩小蛋形态搜索范围；纯色画面快速跳过，慢速识别后留出休息时间。实际更新频率取决于识别耗时与机器性能。

海岛分区按底图岛屿范围划定，部分区域暂用方位命名。小队模式、不同分辨率和游戏更新后的界面仍需要更多实测。无法可靠匹配时保留最后位置，不代表人物仍在该处。

## 本地处理

游戏截图只发送到本机 `127.0.0.1:18731`，不上传云端，不保存捕获画面。程序不读取游戏内存，不控制角色移动。窗口设置、进程号及诊断日志可能写入程序目录。

## 从源码运行

使用 Windows x64、Python 3.13：

```powershell
python -m pip install -r requirements.txt
python server.py
```

浏览器访问 `http://127.0.0.1:18731`。悬浮窗是 Windows 原生窗口，服务应从用户桌面启动；从隔离桌面启动的服务可能无法显示悬浮窗。

## 构建便携版

使用 Windows Python 3.13 x64 的 **embeddable distribution**，准备好 `python313.zip`、`pythonw.exe`、DLL 及 `Lib/site-packages` 中的依赖，并在 `python313._pth` 中启用 `import site` 与 `Lib/site-packages`。

```powershell
path\to\embedded-python\python.exe build_portable.py
```

构建脚本使用 Windows 自带 .NET Framework C# 编译器生成启动与退出入口，按白名单打包应用和素材。产物位于 `portable/`；已有同版本目录时拒绝覆盖。

## 彩虹掉落提示（试用）

正常游戏画面连续两次看到疑似粉紫色光柱、且该帧小地图能确认玩家位置时，自动记录“疑似彩虹·附近”。标记同步显示在网页与地宫悬浮窗中。

这是**发现时玩家所在位置附近**，不是掉落物精确坐标；远处看到的光柱也会记在玩家当时位置。颜色相近的特效可能误报，边缘、遮挡或太小的光柱可能漏检。靠近后请自行核对。控制台可暂停标记、移除已拾取/误报记录或清空；新一局、重新共享及刷新页面会清空。仅保存本次页面会话，不从导入截图生成标记。

已用两张参考截图及多种缩放验证检测，并检查去重、定位丢失、地图切换和悬浮窗绘制；仍需实际游玩验证。

## 入口识别兼容性

补偿整体偏暗的地图截图，并统一较小窗口的门与地形分析尺寸；地图确认阈值不变。三张入口样例的 24 组分辨率、JPEG 压缩和亮度变体通过回归检查，尚不能覆盖所有玩家的失败画面。此补偿不是 HDR 解码，局部颜色偏差仍需失败样例验证。刚进入地宫时请打开大地图，并保留黄门、蓝门和入口房间；两门或地形看不清时，可适当调整地图缩放或向前探索后重试。

## 地图图标大小

宝箱、门等点位默认为此前大小的 85%，底色半透明，以减少地形遮挡。在“地图点位 → 图标大小”中可选择 50%、70%、85%、100%（原大小）或 125%；网页与悬浮窗同步，偏好自动保存。人物定位标记保持醒目。

## 原始点位素材与同步

优先使用 Wikily 地图引用的原始游戏图标，原始字节和来源保存在 data/icons/manifest.json；未生成新的点位图画。蓝门和钥匙房已补齐对应原始图标；缺少素材的普通/特殊房间使用文字。原素材共用宝箱图形，用品质色与金/紫/蓝/绿小字区分。

仅合并同名称、同分类且相距不超过 4 个底图像素的重复记录；不同名称或类别、不同地点保留。大小与点位勾选变更会立即推送到悬浮窗；快速变化的最后一次刷新会补发，即使游戏识别暂停也会更新。原生悬浮窗按现有约 0.25 秒周期读取。

## 实时定位开关

跑图时优先发送左上角小地图进行定位，保留原始裁切像素；小地图消失时，本轮自动补读完整画面。约每 5 秒随识别周期核对一次完整画面，手动“立即识别”和窗口分辨率改变时使用完整画面。打开大地图后的地图识别及校准流程不变。

网页预览最长边限制为 800 像素；开启彩虹掉落检测时同时使用这张小预览检查光柱，关闭后不发送它。浏览器仍共享完整游戏窗口；减少的是本地图片传输、解码与预览处理量，不代表停止整窗采集，也不保证游戏帧率提升。

“游戏画面”区增加“实时定位”开关，默认开启并记忆选择。关闭后保留最后位置，停止小地图匹配与彩虹掉落检测；仍按至少 1 秒的间隔检查游戏大地图（原有 2/3 秒间隔继续沿用），打开大地图可更新地图和位置。重新开启需打开大地图校准，避免移动较远后沿旧位置追踪。

识别当前使用 CPU 上的 OpenCV/NumPy，没有 GPU 匹配加速。内存用于地图索引和缓存。关闭实时定位减少持续计算，不会卸载地图索引，也不会停止浏览器共享本身；需要完全停止画面读取时点击“停止”。

## 悬浮窗地图铺满

悬浮窗根据地图内容自动调整宽高比例，去掉外部留白，保持地形完整和原始比例。拖动边角缩放沿用当前地图比例；切换成长图时会限制窗口尺寸，避免超出屏幕。

## 点位显示设置保存

按图标类别记住开启和关闭选择，网页和悬浮窗使用同一份显示设置。再次识别、切换地宫、手动确认、新一局以及刷新页面后均保留。偏好保存在当前浏览器；旧版本未保存的选择需要更新后重新设置一次。

## 点位素材来源

蓝门与金、紫、蓝钥匙房使用 AniimoTools 地宫地图提供的对应图标；碎岩仔补自《伊莫》官方图鉴。其余地图和原图来自 Wikily。图片保留下载原始字节，各图来源网址与 SHA-256 记录在 data/icons/manifest.json。

伊莫点位使用对应物种的普通形态原图，不冒充幽黯专属图片。开启伊莫类别后按需加载，缩略缓存长边 64 像素。所有类别继续遵循浏览器保存的显示选择，并同步到悬浮窗。
